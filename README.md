# Studi-Kasus-3
Pengelompokan Nilai Ujian Mahasiswa
Program ini digunakan untuk mengelompokkan nilai ujian mahasiswa menjadi dua kelompok, yaitu lulus dan remedi.
Program menggunakan tuple `batas_nilai` untuk menyimpan batas nilai lulus dan nilai maksimal. List `nilai_masuk`, `lulus`, dan `remedi` digunakan untuk menyimpan nilai yang dimasukkan dan hasil pengelompokannya.
Program juga memiliki fitur untuk menghapus nilai yang salah input.
